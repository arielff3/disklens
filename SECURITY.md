# Security

Disklens deletes files and runs some Windows tools as administrator, so security and safety bugs matter a lot. Examples:

- a way to make Disklens delete something it should never touch (a protected folder, a junction target, a path it did not show you),
- a way to run a command or program through Disklens that you did not choose.

## Reporting

Please report these privately through GitHub: **Security → Report a vulnerability** on this repository. Include the steps to reproduce and the Disklens and Windows versions.

You'll get an answer as soon as possible, and credit in the release notes if you want it.

## Supported versions

Only the latest release gets fixes.
